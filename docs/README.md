# Tài liệu tham khảo hệ sinh thái cơ sở dữ liệu eFootball

> **Ngày phân tích:** 2026-09-27
> **Phiên bản phản ánh:** eFootball 2027 (v6.0.0)
> **Datamine datapack:** ~20251204 / các pack hàng tuần đến tháng 9 2026
> **Phạm vi:** Phân tích kỹ thuật toàn diện ba site cơ sở dữ liệu eFootball lớn nhất — **efootbase.com**, **efhub.com**, **pesdb.net** — kèm hướng dẫn tự datamine dữ liệu game từ file gốc Konami.

## Tổng quan

Bộ tài liệu này trình bày phân tích chi tiết về hệ sinh thái cơ sở dữ liệu eFootball: hai site chị em do cùng một công ty (Wild Pluto Sp. z o.o.) vận hành — efootbase.com và efhub.com — cùng với pesdb.net (hoạt động độc lập từ 2011). Tất cả ba site đều dựa trên cùng một nguồn dữ liệu thượng nguồn là file game Konami, nhưng không site nào công khai ghi nhận site khác. Tài liệu cũng mô tả đường ống datamine (WESYS codec, Player.bin parser) đã được dịch ngược và mở nguồn, cho phép bạn tự trích xuất dữ liệu người chơi ngay khi Steam cập nhật — nhanh hơn cả pesdb và efhub.
