## Why

Three small items were left open on purpose by earlier changes and the owner decided them on 2026-10-27: the dimmed stat rows fail WCAG contrast while a category is highlighted, an unknown `<Link href>` passes `pnpm typecheck` and `next build`, and the local database stops after a reboot until OrbStack is started by hand. A fourth decision — what to do about the two old third-party keys in git history — is recorded so it is not asked again.

## What Changes

- **Dimmed stat rows keep readable text.** While a category is highlighted (open Adjust or strip popover, a pinned or previewed category) the other rows are dimmed to opacity 0.4, and axe-core 4.14 reports `color-contrast` on their labels and value pills (2.9–3.7:1; 48–53 nodes on one card, plus the weak-foot chips). The dim is replaced by the least change that makes every dimmed text at least 4.5:1, found by measurement over the real backgrounds and all five tier colours and the chip colours; the highlighted rows keep their accent ring. This is a deliberate, recorded deviation from the reference (which dims to 0.4).
- **Typed links are enforced.** `tsconfig.json` excludes `.next`, so the generated `link.d.ts` is never part of the program. The route types are brought into the program from a tracked file and regenerated by `next typegen` before the type check, so an unknown `<Link href>` fails `pnpm typecheck` and `next build` without ever depending on a stale `.next`. Every existing link that the stricter check rejects is fixed properly (no blanket casts). If enforcement cannot be made fresh and non-breaking, the change stops and records why instead of faking it. *(As built — design "D2 result": the tracked file is `next-env.d.ts`, into which Next itself writes the `link.d.ts` import for the active distDir once `experimental.strictRouteTypes` is set; a fixed-path bridge file was rejected because a `.next-check` build would read the served build's types. This adds one `experimental` key, so the `web-platform-upgrade` requirement "Framework Version And Bundler" is modified to allow exactly that key.)*
- **Postgres after a reboot.** The compose file already has `restart: unless-stopped` and the live container reports it; no file change. OrbStack's "start at login" is off and cannot be set from the command line (`orb config set app.start_at_login true` leaves it `false`); the exact manual step and the command that proves it are documented. Nothing claims it is enabled.
- **Keys in history.** Owner decision of 2026-10-27, recorded in `CLAUDE.md`: keep the two old third-party keys in git history and accept the risk (no history rewrite; rotation is the key owners' side, not ours).
- **Docs**: `CLAUDE.md` (Known limitations: the dimmed-row item removed, the typed-link gap closed, the key decision, the OrbStack step in "Running"), `openspec/ui-dna.md` ("Highlight" deviation), README only if it states any of these.
