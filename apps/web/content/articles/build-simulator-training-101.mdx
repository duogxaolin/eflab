# Build Simulator 101

The eFootball Lab build simulator computes the projected stat outcomes for
each training-point allocation. Here's how to spend the budget wisely.

## General principles

- **Front-load your strength stat.** The category your player is best at
  yields more point-for-point than balanced spend, because category caps
  close faster.
- **Use booster slots for +2/+3 narrow boosts.** Wide boosts are for
  utility roles; narrow boosts are for specialists.

## Position templates

### AMF

- **Shooting** + Passing: each +4
- **Dribbling**: +8
- Boost: `Passing +3` + `Shooting +2`

### CB

- **Defending** + Lower Body: each +6
- **Aerial**: +4
- Boost: `Aerial +2` + `Duelling +2`

### CF

- **Shooting** +6 / **Dribbling** +2 / **Lower Body** +4
- Boost: `Shooting +2` + `Technique +2`

## Common mistakes

- **Spending in the 5-point category on the wrong axis** — the simulator
  shows diminishing returns after the first 4 points; rebalance there.
- **Ignoring Weak Foot** — for wide roles, Weak Foot Accuracy ≥ 3 matters
  more than any single stat.

Use the **Build** button on any player card page to test these templates
without committing them. Once the build lands where you want, save it
publicly to help the community.
